5. На защите нужно понимать код: защита составляет 40% оценки. Коротко повтори:
   - DOM: JavaScript выбирает элемент и меняет его текст, атрибут или класс.
   - addEventListener: связывает событие с функцией.
   - callback: функция, переданная другой функции; здесь showStep передаётся changeStep.
   - switch: выбирает правило фильтра по рейтингу.
   - object / method: объект хранит поля, метод — его функция; this.price берёт цену текущего отеля.
   - array / loop: hotelsDatabase хранит отели, for выводит каждый отель.
   - higher-order function: filter принимает функцию-проверку и возвращает подходящие элементы.
   - sound: один Audio переиспользуется; pause и currentTime = 0 перезапускают его.
   - animation: JS добавляет CSS-класс, а @keyframes описывает движение.

Даты в примере можно заменить на другие: выезд должен быть позже заезда.
