BookingApp: как объяснить Assignment 5

1. Структура проекта

HTML описывает элементы страницы. CSS задаёт оформление и анимации. JavaScript реагирует на действия пользователя и меняет страницу.

У трёх групп страниц остались свои файлы:
index.html и search-results.html используют script.js и allstyle.css.
booking.html и hotel-detail.html используют booking.js и style.css.
about.html и services.html используют about-services.js и ablstyle.css.
Навигация стрелками, звук кнопок и нужные стили находятся в существующих файлах каждой группы. У каждой пары страниц остаются только её собственные JavaScript и CSS.

2. Что уже сделал тиммейт

Он добавил массив объектов с данными отелей, создание карточек через JavaScript, фильтр рейтинга через switch и файл click.mp3. Эта работа сохранена и дополнена.

Массив хранит несколько элементов в одном месте. Каждый объект отеля хранит его название, город, цену, рейтинг и другие свойства.

renderHotels получает массив и показывает карточки. Сначала контейнер очищается. Затем для каждого отеля создаётся article, заполняется его содержимое и добавляется на страницу.

3. Поиск и фильтры

При отправке формы вызывается обработчик submit. event.preventDefault() отменяет обычную перезагрузку страницы.

switch выбирает действие по выбранному рейтингу. Значение 4 означает рейтинг не ниже четырёх, поэтому пятизвёздочный отель тоже подходит.

filter создаёт новый массив только из подходящих отелей. Исходный массив не удаляется. После проверки условий renderHotels снова рисует результат.

filter и forEach принимают другую функцию в качестве аргумента. Поэтому они являются примерами функций высшего порядка.

4. Навигация с клавиатуры

Сначала пользователь ставит фокус на ссылку меню с помощью Tab. Обработчик keydown проверяет, какая клавиша нажата.

Стрелки переводят фокус на следующую или предыдущую ссылку. Метод focus() переносит фокус. Enter открывает выбранную ссылку обычным способом.

5. Read More и DOM

На странице отеля кнопка раскрывает дополнительный текст и скрывает его при повторном нажатии. Одновременно меняются надпись на кнопке и aria-expanded.

DOM - это представление HTML-страницы в виде объектов. getElementById и querySelector находят нужные элементы. textContent меняет текст, а classList, hidden или style меняют видимость и оформление.

6. Многошаговая форма бронирования

Форма разделена на шаги: данные гостя, параметры проживания и просмотр результата. Переменная текущего шага показывает, какая часть формы сейчас открыта.

Кнопка Next проверяет поля текущего шага. Если есть ошибка, форма показывает сообщение и остаётся на этом шаге. Back возвращает к предыдущему шагу. Значения сохраняются, потому что поля не удаляются и не создаются заново.

Callback - это функция, переданная в другую функцию. В форме функция перехода получает функцию, которая показывает нужный шаг. Она вызывает её после успешной проверки.

Объект с методами расчёта получает данные проживания и считает количество ночей и итоговую цену. Метод - это функция внутри объекта. this обращается к свойствам и другим методам этого же объекта.

Финальная отправка показывает результат демонстрации. Реальное бронирование и учётная запись не создаются.

7. Расчёт стоимости услуг

Массив services хранит услуги, цены и единицы расчёта. Цикл for проходит по массиву и создаёт варианты выбора.

Объект serviceEstimator имеет методы getService и calculateTotal. Первый находит выбранную услугу, второй умножает цену на количество.

Например, аренда автомобиля стоит 35 долларов за день. При количестве 3 результат равен 35 * 3 = 105 долларов.

После расчёта текст результата обновляется через textContent. CSS-класс запускает небольшую анимацию появления.

8. Звуки и анимации

Audio загружает click.mp3. При нажатии кнопки воспроизведение начинается с начала. Используется один объект Audio, поэтому несколько нажатий не создают несколько одновременно играющих копий.

JavaScript запускает анимацию через событие: например, показывает новый шаг или результат расчёта. Само оформление анимации находится в CSS.

9. Что осталось от Assignment 4

Проверка полей, popup подписки, FAQ, смена фона и часы были в старом проекте. Они продолжают работать. setInterval обновляет часы раз в секунду.

10. Короткий ответ для защиты

Мы продолжили BookingApp. Данные отелей хранятся в массиве объектов. JavaScript создаёт карточки и фильтрует их без перезагрузки. События click, submit и keydown управляют интерфейсом. Для выбора логики применяется switch. В форме используются шаги и callback. Расчёты выполняют методы объектов. Есть обычный цикл for, функции высшего порядка, звук и анимации. HTML, CSS и JavaScript разделены на файлы.

Сайт опубликован на Vercel: https://aishhko.vercel.app/. Код проекта: https://github.com/jjestar/web. Все формы остаются учебной демонстрацией без реального бронирования или отправки сообщений.

11. Как передаётся выбранный отель

Общий файл js/hotels.js хранит данные трёх отелей. У каждого есть уникальный id: grand-palace, ocean-view или comfort-city. Карточка добавляет этот id в ссылку, например hotel-detail.html?hotel=ocean-view.

getSelectedHotel читает параметр hotel через URLSearchParams и находит объект в массиве через find. Страница деталей показывает название, фотографии, удобства и цену этого объекта. Кнопка Book This Hotel передаёт тот же id на страницу бронирования.

Бронирование использует цену выбранного отеля: Standard равен базовой цене, Deluxe стоит на 40 долларов больше, Suite - на 100 долларов больше. Итог равен цене комнаты за ночь, умноженной на число ночей. Название отеля есть в итоговой сводке. Если id отсутствует или неизвестен, открывается Grand Palace Hotel.
